# 📝 অনলাইন MCQ পরীক্ষা প্ল্যাটফর্ম

জীববিজ্ঞান, পদার্থবিজ্ঞান ও রসায়ন বিষয়ে অধ্যায়ভিত্তিক অনলাইন MCQ পরীক্ষা নেওয়ার জন্য একটি সম্পূর্ণ Streamlit অ্যাপ।

## ✅ ফিচার সমূহ

- **শিক্ষার্থী অংশ:** নাম ও শ্রেণি দিয়ে প্রবেশ → বিষয়/অধ্যায় নির্বাচন → লাইভ কাউন্টডাউন টাইমারসহ পরীক্ষা → সময় শেষে অটো-সাবমিট → ফলাফল ও উত্তরপত্র পর্যালোচনা
- **এডমিন অংশ:** পাসওয়ার্ড সুরক্ষিত প্যানেল, অধ্যায় যোগ/এডিট/মুছে ফেলা, একসাথে অনেক প্রশ্ন পেস্ট করে যোগ করা, প্রশ্ন এডিট/মুছে ফেলা, সময়-মার্ক সেটিংস, পরীক্ষা চালু/বন্ধ নিয়ন্ত্রণ, ড্যাশবোর্ড, মেধাতালিকা (CSV ডাউনলোডসহ)
- ডাটা সংরক্ষিত হয় স্থানীয় SQLite ফাইলে (`exam_data.db`) — কম্পিউটার/সার্ভার রিস্টার্ট করলেও ডাটা থেকে যায়।

## 🚀 চালু করার নিয়ম (নিজের কম্পিউটারে)

```bash
pip install -r requirements.txt
streamlit run app.py
```

তারপর ব্রাউজারে যে লিংক (যেমনঃ `http://localhost:8501`) আসবে, সেটিই শিক্ষার্থীদের প্রবেশের ফিক্সড লিংক। সাইডবার থেকে "এডমিন" নির্বাচন করে পাসওয়ার্ড দিয়ে এডমিন প্যানেলে ঢোকা যাবে।

## 🌐 ইন্টারনেটে সবার জন্য উন্মুক্ত করতে (ফ্রি হোস্টিং)

1. এই ফোল্ডারটি একটি GitHub রিপোজিটরিতে আপলোড করুন।
2. [share.streamlit.io](https://share.streamlit.io) (Streamlit Community Cloud) এ গিয়ে GitHub দিয়ে লগইন করুন।
3. "New app" → রিপোজিটরি সিলেক্ট করে `app.py` দিন → Deploy করুন।
4. কিছুক্ষণ পর একটি স্থায়ী (fixed) লিংক পাবেন, যেমনঃ `https://your-app-name.streamlit.app` — এই লিংকটিই শিক্ষার্থীদের দিন।

> ⚠️ বিঃদ্রঃ Streamlit Community Cloud-এ অ্যাপ কিছুক্ষণ নিষ্ক্রিয় থাকলে স্লিপ মোডে চলে যেতে পারে এবং ফ্রি প্ল্যানে ফাইল-ভিত্তিক ডাটাবেজ (`exam_data.db`) রিস্টার্টের পর মুছে যেতে পারে। দীর্ঘমেয়াদে অনেক শিক্ষার্থীর জন্য ব্যবহার করলে Railway, Render বা VPS-এর মতো পার্সিস্টেন্ট স্টোরেজসহ হোস্টিং ব্যবহার করা ভালো।

## ✍️ প্রশ্ন পেস্ট করার ফরম্যাট

এডমিন প্যানেলের "প্রশ্ন যোগ/এডিট" ট্যাবে বাল্ক পেস্ট বক্সে এই ফরম্যাটে লিখুন:

```
প্রশ্ন: বাংলাদেশের রাজধানীর নাম কী?
ক) চট্টগ্রাম
খ) ঢাকা
গ) সিলেট
ঘ) রাজশাহী
উত্তর: খ

মানবদেহের সবচেয়ে বড় অঙ্গ কোনটি?
ক) হৃদপিণ্ড
খ) যকৃত
গ) ত্বক
ঘ) মস্তিষ্ক
উত্তর: গ
```

- "প্রশ্ন:" শব্দটি না লিখলেও চলবে।
- একাধিক প্রশ্ন একসাথে পেস্ট করা যাবে — প্রতিটি প্রশ্নের ব্লক আলাদা রাখলেই স্বয়ংক্রিয়ভাবে আলাদা হয়ে যাবে।
- ভুল ফরম্যাটের প্রশ্ন থাকলে সিস্টেম কোনটি বাদ পড়েছে তা জানিয়ে দেবে, বাকি সঠিকগুলো ঠিকই যোগ হবে।
